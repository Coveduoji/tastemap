# TasteMap 界面美化 · 第一轮

## 分析

项目以 Flutter + Provider 构建，数据层与页面基本分离，主题已集中到 colors / typography，可在不迁移框架的情况下迭代视觉。主要体验问题：

- 通用正文仅 12，部分收藏文字只有 7，阅读负担较大。
- 地图有全屏优势，但收藏入口与查看收藏的路径分散；已有标签筛选状态没有在首页呈现。
- 个人页采用头像、统计和地图占位块，信息密度与视觉重心不均衡。
- 设置与收藏页的白色背景和白色内容缺少层次。

## 设计方向与实现

参考苹果原生应用的系统字体、分组背景、圆角卡片和轻量导航；结合圆周旅迹公开截图的蓝白色调、地图加卡片组织方式。保留 TasteMap 个人地点收藏的定位。

- 配色：蓝色强调、深色主文字、浅灰页面、白色卡片。
- 字体：系统无衬线及中文回退；正文 15、说明 12、标题 18–24。
- 地图：增加横向分类筛选，连接已有 Provider；新增底部半透明收藏入口及添加按钮；考虑底部安全区；搜索和个人按钮扩大至 48。
- 地图标记：白边与阴影提高地图上的辨识度，实蓝与白底分别表达已打卡、待打卡。
- 个人页：足迹标题、三列统计、返回地图入口、收藏与城市分组；补充无数据提示。
- 设置与收藏：浅灰背景、白色分组、统一返回图标与标题。
- 公共组件：统一输入框、提示条、弹层圆角、页面过渡。
