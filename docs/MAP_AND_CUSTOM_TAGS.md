# 中心选点、自定义标签与地图交互

- 常驻蓝色中心标记，点击进入该坐标的命名收藏；长按地图可直接选点收藏，单击地图将所选坐标移至中心。
- 地图加载附近真实地点为可点击标记；点击直接打开对应地点收藏表单。
- 增加缩放、朝北复位和定位控件；保留双指缩放、拖动和旋转。聚合标记点击后以该簇为中心放大。
- 地图停稳后防抖查询附近地点，忽略过期请求；缩小到城市尺度时隐藏附近地点标记。
- 类型和二级标签末尾添加自定义按钮；新增后自动选中，保存到 app_settings，下次表单继续复用。新增类型也用于地图筛选。
- 自定义类型以带 custom: 前缀的名称编码保存到现有 primary_tag 字段，无需破坏性数据库迁移；旧内置分类编码不变，自定义名称可随收藏备份往返。
- 编辑收藏补全二级标签、图片预填，避免编辑保存丢失原有内容。
- 系统返回键优先关闭收藏面板；地点解析显示加载状态；保存防重复提交。

## 历史地图边界（本轮后已接入 Android 原生地图）

当前为高德栅格底图 + 高德 Web 服务 + Flutter 可交互地点层。栅格瓦片里印刷的文字本身没有原生 POI 点击事件；可点击的是应用加载出来的地点标记。完整高德原生 SDK 的矢量地图、建筑、室内图等需要 Android SDK Key（区别于现有 Web 服务 Key），本轮没有声称已接入。
