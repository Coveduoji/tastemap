## 地图

Android 在配置本地 Android SDK Key、用户完成首次服务说明确认后，使用高德原生矢量地图（TextureMapView）。未启用原生地图的平台继续使用现有地图。Key 只位于 Git 忽略的 lib/config.dart。

- 地图文字、住宅、办公、交通等系统 POI 由高德 SDK 绘制；应用只额外绘制自己的收藏。
- 原生 POI 点击进入收藏表单；地图地点分类与个人标签分离，住宅不再默认为美食。
- 高德 Web 搜索保留 typecode/type，附近列表显示真实地图分类；无对应个人分类时默认“未分类”。
- 位置经 WGS84 → GCJ-02 转换后再显示，避免底图偏移。
- 标准地图 / 卫星地图切换，地图 View 跟随 Activity 生命周期释放资源。

## 聚合规则

距离单位为逻辑屏幕像素（dp），与设备像素密度和纬度无关。

| 缩放级别 | 最大聚合直径 |
| --- | --- |
| 小于 12 | 52dp |
| 12 至小于 14 | 40dp |
| 14 至小于 16 | 28dp |
| 16 及以上 | 不聚合，单点展开 |

聚合气泡固定 24dp，数字 10dp；点击聚合后适配其成员范围，最多放大到 16.5 级并在街道级展开。重叠单点通过细线引出，保持可点击间距，真实收藏坐标不变。限制簇的最大直径，避免邻近地点串联成过大的簇。

## 自定义选项删除

自定义类型、二级标签旁提供 ×。删除前说明影响并确认。

- 删除类型：相关收藏改为“未分类”，地点、备注、图片保留；当前筛选复位。
- 删除二级标签：从已有收藏移除该标签关联；保留其他内容。
- 选项和关联记录在同一 SQLite 事务中更新，重启后不会从历史记录中复活。
- 内置选项不提供删除按钮。

## 面板手势

手柄和空白区域支持下拉；列表可自然缩回，缩到关闭阈值后退出。加载时即使列表未挂载，也可通过下拉关闭。关闭时收起键盘。
