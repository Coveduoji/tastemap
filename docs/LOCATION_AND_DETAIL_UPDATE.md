# 定位与详情交互更新（上轮记录）

最新的定位、收藏入口和性能改动见 [MAP_PERFORMANCE_AND_COLLECTIONS.md](MAP_PERFORMANCE_AND_COLLECTIONS.md)。

## 定位

原主地图依赖 Geolocator 获取系统坐标，再等待 Web 坐标转换。原生地图现在直接使用 amap_map 已有的高德定位回调，其坐标已经适用于高德地图，减少系统融合定位和Web转换两处依赖。

Android补齐 APSService、SDK Key元数据和 Wi-Fi状态权限。Key继续来自忽略的lib/config.dart（或AMAP_ANDROID_KEY环境变量），没有写入版本控制中的明文配置。权限、系统位置服务关闭和定位超时分别处理；手动点击时提供相应提示与设置入口。非高德地图路径保留Geolocator，Android明确使用系统LocationManager。定位请求不会在用户已切换地点后把视图拉回。

以上是代码层修复，未操作真机验证定位结果。

## 入口

- 搜索选择地点：地图移动到该地点，展示详情面板。
- 加号：附近列表，选中后直接进入收藏表单，不再自动插入详情。
- 原生地图POI：直接进入收藏表单，后台补齐真实地点分类。
- 收藏卡片和表单中点击名称：仍可主动打开详细信息。

## 面板与底图

详情采用 Flutter Scaffold.showBottomSheet + DraggableScrollableSheet，无新建平台桥或手势框架。面板列表连接标准滚动控制器，支持上拉展开、下拉到最小高度关闭；底层是该地点附近的标准高德地图。地图视口随面板高度调整，定位目标保持在可见地图中，地图手势仍可操作。收起后恢复主地图控件。卫星地图仍不提供。

## 信息

本轮补齐高德请求字段和解析，包括商圈、特色、每周营业时间、楼层、停车类型、别名、子地点，增加周边公交/地铁/停车设施。继续展示照片、地址、电话、评分、价格及个人收藏内容。字段缺失时不造值。

市场数据源比较与后续建议见 [PLACE_DATA_RESEARCH.md](PLACE_DATA_RESEARCH.md)。其中第二来源建议为百度地点详情3.0，需要对应Key和权限后再接入；本轮没有接入未授权的第三方数据。
