# 上轮变更记录

当前定位与详情交互已调整，见 [LOCATION_AND_DETAIL_UPDATE.md](LOCATION_AND_DETAIL_UPDATE.md)。

使用现有 Flutter 工程，不新增脚手架。地图由 amap_map 1.0.15 管理原生通信与生命周期；移除自建 Kotlin 平台桥。下拉面板使用 Flutter BottomSheet / DraggableScrollableSheet，搜索使用 SearchDelegate。UUID、网络、导出、文件选择、分享、通知、凭证存储分别使用 uuid、Dio、csv、file_picker、share_plus、flutter_local_notifications、flutter_secure_storage。

## 交互

- 主提示只在首次打开时出现，可关闭，已显示状态持久化。
- 精简填写页重复标题；附近和收藏面板下拉关闭，移除关闭和重新选择按钮。
- 顶部搜索查全国地点，选择后先进入详情；原生地图 POI 同样进入详情。
- 已收藏地点卡片名称可点击进入详情；已收藏详情优先展示个人类型与标签。
- 详情以高德 POI ID 查询为主要来源，老收藏按精确名称与150米范围匹配；展示服务实际返回的照片、地址、电话、营业时间、评分和消费字段，以及个人备注和照片。缺失字段不补造。保留高德原始地点链接。

## 聚合

| 缩放级别 | 当前唯一应用标记层 |
| --- | --- |
| <5 | 国家聚合 |
| 5–<8 | 省聚合 |
| 8–<11 | 市聚合 |
| 11–<14 | 区聚合 |
| ≥14 | 单个收藏点 |

使用完整行政路径分组，跨省同名区不会混合。缺失行政数据的地点单独保留，后台补全后归组。聚合层包含单成员区域，点击逐层放大；不同时叠加收藏标记和聚合标记。底图原生地名仍由高德显示。

SQLite v1→v2仅新增行政区、POI ID与地址字段，保留原记录。升级前已备份预览包数据库。

## 设置

- JSON/CSV 导出可保存文件或调起系统分享；CSV 处理引号、换行、中文与公式前缀。JSON保留照片路径，不打包照片文件。
- 统一标准高德地图，移除卫星地图能力；地图缓存调用 SDK 清理。
- 附近收藏提醒使用定位和系统通知，限定应用使用期间、150米、每日每个地点一次；需要通知与定位授权。
- WebDAV 使用已有成熟客户端，备份前创建目录，恢复前确认覆盖；密码迁移到系统安全存储。
- 版本信息取真实包信息；反馈打开 GitHub 问题表单，由用户提交；说明、清空收藏均有实际功能。
- 未提供 WebDAV 账户，不能声称云端备份恢复已端到端验证。
